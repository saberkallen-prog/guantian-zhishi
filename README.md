# 观天知时 · 节气农田

二维互动农田原型，原生 HTML / CSS / JavaScript，无第三方运行时依赖。

## 本地使用

直接双击 `dist/index.html`，或在本目录运行 `node preview.cjs`，然后打开终端打印的地址。

## 功能

- 连续拖动节气滑块，24 个生长关键状态之间实时过渡；支持前后导航、四季快速选择与自动生长播放。
- 同一片田中的稻株高度、疏密、稻穗和颜色变化；育秧、收割稻茬、水面与冬日霜色联动。
- 静态田园插画底景与 Canvas 实时庄稼叠加，保留三处讲解热点。
- 农事操作反馈、当前浏览器中的手记持久化、文本导出。
- 浏览器语音讲解、天文知识与资料来源弹窗。
- 田间晴、雨、雪切换；雨落稻叶、雪落稻茬的动态特写。
- `terms.html`：24 节气图鉴，包含名称含义、自然变化和生活农事，可按四季筛选。
- `sun.html`：太阳黄经、地球公转位置、直射纬度、北纬35°正午日影与近似白昼时长联动；支持拖动和播放。
- 适配桌面和手机，支持键盘、原生弹窗及减少动态效果偏好。

## 验证

`node --test tests/model.test.cjs tests/learning.test.cjs`

## 内容边界

以江南单季稻作为灵感的教学示意，节气与作物阶段为演示编排，不作具体地区、特定历史时期的农业生产指导。田园底景为 AI 生成插画，庄稼以 Canvas 实时绘制；24 组关键状态之间连续插值，不是经过标定的农艺生长模型。日期为常见公历交节范围，非某年精确时刻。

雨雪是艺术化天气演示，不表示江南某个节气必然下雨或下雪。太阳页面使用现代定气法与简化圆形公转图，太阳直射纬度按黄赤交角约23.44°近似计算；正午日影和白昼时长采用北纬35°的几何模型，忽略大气折射、太阳视半径和地形，不作精确天文年历或古代历法复原。

## 文件

- `dist/index.html`：界面。
- `dist/style.css`：响应式样式。
- `dist/model.js`：节气数据与手记状态。
- `dist/field.js`：田块、稻株、稻穗与水面的实时绘制。
- `dist/field.css`：连续时间滑块样式。
- `dist/weather.js`：田间降水叠加与雨雪特写。
- `dist/learning.js`、`dist/learning.css`：节气图鉴与太阳页面的交互及样式。
- `dist/app.js`：交互与浏览器存储。
- `dist/assets/field-base.webp`：无作物的田园底景，动态作物与它分层呈现。
- `ASSET-PROMPT.md`：图像生成提示词及工具说明。

数据来源可在网页“素材与出处”中查看。
